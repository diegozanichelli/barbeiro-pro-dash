# Performance Barber

Sistema de gestão de performance, metas e comissões para barbearias.

## Tecnologias

- Vite
- TypeScript
- React 18
- Tailwind CSS
- shadcn/ui
- Supabase

## Desenvolvimento local

Requisitos: Node.js >= 20 e npm >= 10.

```sh
# Instalar dependências
npm install

# Subir o servidor de desenvolvimento
npm run dev

# Build de produção
npm run build
```

## Estrutura

- `src/` — aplicação React
- `supabase/` — migrations e edge functions
- `public/` — assets estáticos e PWA
